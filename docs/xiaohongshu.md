# 小红书图文笔记导入

## 开源来源

采用 [ReaJason/xhs](https://github.com/ReaJason/xhs) 的 MIT 授权 HTML 提取逻辑，固定提交 `f4b62d9f8e4078e631fc6e4ec8e430bc711ee9f0`。复用范围和修改见 [第三方声明](../THIRD_PARTY_NOTICES.md)，许可证原文见 [xhs-LICENSE](../third_party/xhs-LICENSE)。没有引入上游整个 SDK，也没有复用签名或互动接口。

## 使用

1. 在小红书 App 中复制一篇图文食谱的分享链接。
2. 在食拾点击“导入食谱”，粘贴完整分享文案或链接。
3. 系统读取标题、作者及笔记正文，显示原文和食谱草稿。
4. 核对正文中的用量和步骤，补全缺失字段，再保存。

支持 `www.xiaohongshu.com/explore/笔记编号`、`www.xiaohongshu.com/discovery/item/笔记编号` 和 `xhslink.com` 短链。签名分享链接中的 `xsec_token` 用于本次请求，不写入正式来源字段。按笔记编号去重，不因分享参数变化重复保存。

正文只有存在明确的“食材 / 用料 / 材料”和“步骤 / 做法”等段落时才按规则拆分。未找到段落时，草稿对应字段留空并提示补充；保留原始正文，不生成新食谱。不会识别图片中的材料和步骤，也不处理视频笔记。

## 登录态（可选）

先尝试不登录读取。遇到需要登录的笔记，可在本机 PowerShell 配置自己的登录态，再启动后端：

```powershell
$env:XHS_COOKIE = '你自己的小红书 Cookie'
.\.venv\Scripts\python.exe -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

Cookie 只从进程环境读取，后端仅向小红书笔记域名发送，短链域名不会收到这个请求头。食拾不将 Cookie 返回前端、写入数据库或提交到 Git，也不会自动从浏览器读取账号。登录态失效后需要自行更新。分享链接可失效；若无 xsec_token，请重新从 App 复制完整链接。

遇到验证码、登录跳转、访问限制或正文不可读，导入会停止并说明原因。没有接入自动登录、自动验证码处理或批量抓取。

## 验证

自动测试覆盖：签名参数与去重、两种长链接、短链解析、非平台跳转拒绝、Cookie 域隔离、JSON 状态解析、undefined 文本保留、原文持久化、不完整草稿、调料分类、视频拒绝与登录/验证失败。固定样本为测试自建正文，不冒充真实笔记抓取成功。
