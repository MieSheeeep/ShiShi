# 首页每日精选实施计划 · 2026-11-10

目标：在已确认的首页横幅位置展示本地当天精选，支持查看往期、收藏编辑；全站统一深松绿与暖纸白。

架构：独立 Vue 组件负责今日卡片与往期；本地内容模块负责日期选择、排期及转换为现有 V2 食谱草稿。使用现有编辑保存流程，不改数据库，不自动写入用户收藏。
