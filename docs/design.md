# 食拾本地初版

范围：单用户本地运行，Vue 3 前端、FastAPI 后端、SQLite 持久化。仅支持豆果 cookbook 链接；没有大模型依赖。收藏库、分类搜索、编辑详情、步骤勾选、食材匹配、采购清单形成闭环。演示食谱明确标识为内置示例。

导入采用同步请求，最多等待 20 秒，先预览再保存；允许编辑。只接受 www.douguo.com/cookbook/数字.html，禁用重定向，限制响应大小。优先 JSON-LD，回退豆果材料表和步骤节点；遇到验证码或缺少材料、步骤时拒绝导入。来源链接唯一，重复返回冲突。

材料用十进制求和，支持克/千克、毫升/升换算；个数与重量分组，模糊用量保留文字。别名支持西红柿→番茄、马铃薯→土豆。按缺料数量排序。采购清单独立保存，可修改用量并勾选，保留来源。

界面：米白底、深绿色侧栏、卡片式食谱库。移动端导航折行。所有用户内容作为文本渲染。

验收：解析固定 HTML 样本；材料合并与别名测试；接口保存、重复、编辑、匹配、清单持久化测试；前端生产构建与浏览器检查。
