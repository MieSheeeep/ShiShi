# 首页每日精选：已确认方向

## 定位

首页以当天的一道精选食谱为核心，用户可以查看往期。现有个人食谱库继续承担收藏与编辑功能。

第一阶段使用本地固定内容，按日期预先规划；结合中国节气、传统节日和日常饮食需要，体现健康饮食与中国饮食文化。

## 每日内容

- 今日推荐：一道精选做法，图片与食谱为主角。
- 推荐理由：为什么适合今天，结合节令、节日或实际做饭场景。
- 饮食文化小记：有相关背景时介绍食物来历、地域习俗或历史记载；核实出处，不强行每天加入典故。
- 一餐搭配：帮助用户将这道菜安排进实际的一顿饭。
- 素材来源：记录食谱作者、链接、图片使用依据及文化资料出处。

## 内容与呈现原则

- 当天内容为主要展示，往期入口为辅助。
- 美观体现在高质量食物图片、精炼标题与文案，以及内容整体协调。
- 历史厚重感来自真实、有出处的饮食文化内容。
- 不采用书本、翻书或古籍式产品概念，不将整站改成书本视觉。
- 不强行将所有菜品与节气绑定；历史饮食记载与现代改编做法分清。
- 健康内容侧重食材组合、用量和烹饪方式，不凭不完整食谱给出精确营养评分或功效承诺。
