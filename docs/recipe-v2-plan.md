# 食谱 V2 与可排序编辑 · 2026-11-04

用户已确认统一可编辑格式和分组自定义标签，并强调采集顺序可能错误，必须支持修改和排序。

设计：SQLite 仍保存完整食谱 JSON。schema_version=2，每个材料和步骤具有稳定 ID，步骤包含文字和图片；来源保存独立原文和原图。原始导入快照在首次导入时创建，后续编辑不覆盖。旧记录只能保留迁移时版本，明确标为 legacy_saved，不声称恢复了此前原始内容。迁移自动备份数据库，原子更新现有记录。旧请求和解析器输出在 API 边界兼容转换。

标签：独立 tag_groups、tags 表，食谱保存 tag_ids，API 返回解析后的分组/名称。支持创建、重命名、移除和多个标签同时筛选；重命名同步所有关联食谱。来源平台单独存储，旧标签迁移至“我的分类”。

编辑：材料/步骤/图集均支持上移下移；步骤可在任意位置插入、删除，图片可手动关联到步骤、调整顺序或移除引用。所有图片保持本地保存，原始快照和原图不随编辑丢失。取消或误触关闭有未保存提示。
